# Tests

Plain Node scripts — no framework, no install for the first two.

## Running them

```
npm i --no-save playwright            # the browser tests' only dependency (package.json is gitignored)
node tests/run-all.js                 # every *.browser.js / *.test.js, one at a time, with a summary
node tests/run-all.js calendar        # only files whose name contains "calendar"
node tests/qc-infra.browser.js        # any single script runs on its own
```

- **`run-all.js`** runs each script in its own process, prints `PASS`/`FAIL` per file (with the
  failing lines), and exits non-zero if any script fails or runs longer than `SM_TEST_TIMEOUT` ms
  (default 240000). The whole suite takes about 20 minutes.
- **`SM_CHROME`** — the Chromium binary the browser tests launch. Every script falls back to
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` (a few older ones also read `CHROME`).
  With a normal Playwright install: `export SM_CHROME="$(node -e "console.log(require('playwright').chromium.executablePath())")"`
  after `npx playwright install chromium`.
- **`NODE_PATH`** — point it at a `node_modules` that has Playwright when it is not installed in
  this checkout, e.g. a git worktree: `NODE_PATH=/path/to/main/checkout/node_modules node tests/run-all.js`.
- The scripts open `index.html` relative to this folder (`file://…/index.html`), so they run from
  any checkout location. There is no network: tests stub `fetch` / `chatCompletion`.
- CI: `.github/workflows/tests.yml` does exactly the above on every push and pull request.
